# Agile Sprint Review Demo Script Template

A multi-step form that generates a complete, printable sprint review meeting script for agile teams.

## Features
- Four input sections: Sprint Info (number, dates, team, goal, goal-met status), Demo Items (add unlimited items with description and outcome), Metrics (velocity, story points, bugs closed/opened, capacity), and Backlog & Next Sprint
- Add unlimited demo items dynamically, each with description and outcome text
- Generated script follows a structured agenda: Opening, Goal Review, Feature Demos, Metrics, Backlog Updates, Next Sprint Preview, Open Questions, Closing
- Copy to clipboard and Print buttons on the script output
- localStorage autosaves all data as you type across sessions

## Usage
Work through the four tabs (Sprint Info, Demo Items, Metrics, Backlog & Next), then click "Generate Script" or navigate to the Script tab. The formatted script is ready to copy or print for your meeting.
